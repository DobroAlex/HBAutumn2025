# HBAutumn2025
HB 2025 code samples

* test -- общая папка всех тестов
  * private -- тесты, которые ломают только себя и не "протекают" на соседей.
  * leaking -- тесты, которые необязательно ломают себя, но с большой долей вероятности ломают соседей.


### Замечания по запуску и окружению

Python 3.13, протестировано на Windows 10. 

Если в тестах не указаны явно параметры кол-ва воркеров (n == X),
то можно считать n == 1.

Некоторые тесты работают только под Windows и требуют админ прав -- это явно указано в файле.


По всем вопросам/багам/ньаюнсам -- заводите ишаки, будем вместе дебажить
